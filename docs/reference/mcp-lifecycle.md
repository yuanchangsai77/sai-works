# MCP 连接生命周期

范围：本地 MCP 管理器、客户端以及 Stdio、Streamable HTTP、SSE 传输。MCP wire 字段、错误码和远端工具契约不变。

管理器可跨轮复用，但客户端与传输实例关闭后不能复活。新运行可创建新实例；旧工具上下文和旧代际请求不得触发重连。初始化结果发布前重新检查代际，关闭前开始的初始化不能混入下一轮。失效操作绑定具体客户端，旧请求失败不能关闭替代客户端。

客户端初始化及操作串行化；传输的请求与通知也共享协议交换锁，避免响应队列串线、重复握手和 HTTPConnection 并发状态冲突。排队操作获得锁后再次检查关闭状态。关闭使用独立生命周期锁并唤醒响应等待者；它不等待协议交换锁，但已开始的连接建立或请求派发仍可能受配置的网络超时约束。

关闭逐个尝试客户端和 SSE 活动连接。失败实例保留供重试，同一服务器在失败清理完成前不得重建客户端。连接在网络建立前进入清理归属，部分建立失败后仍可关闭。Stdio 的本地进程组清理复用[工具执行与资源生命周期](tool-execution.md)；不同平台的保证范围也相同。

HTTP 404 会话过期的只读恢复使用内部会话重置，与实例永久关闭区分。`tools/call` 不在失效或断线后自动重放。本地连接关闭、响应等待结束和服务器接受取消，都不能单独证明远端副作用已停止。
