# 工具执行与资源生命周期

范围：同进程工具调用、可信执行阶段、本地资源与进程组清理。`ToolAction`、模型工具定义及对外 `ToolResult` 格式不变；阶段凭据只在内部传递。

## 执行阶段与重试

注册表保留既有 `execute` 入口，并提供内部 `execute_tracked`，二者共用一套实现。每次调用返回独立的结果及阶段：未知、未启动、已启动；凭据不可变，不使用共享“最近结果”槽，也不读取远端 metadata。普通执行入口继续拒绝并发或重入；受控只读批次由注册表统一持有执行锁，不允许其他执行入口穿插。

### 受控本地只读批次

同轮连续、不同参数、目标已在当前工作区授权内的可信本地只读动作最多四项组成一个批次。工具实现必须显式声明隔离读取支持，不能仅凭 read 风险等级并发；首批支持文件读取、文件信息和目录列举，搜索、Git、Shell、写入、工作区切换、能力管理及未知扩展均为串行边界。重复动作和需要外部路径授权的动作也是边界，保留既有去重与按需审批行为，不并发发起新授权。

可见性、去重、前置校验、委托范围、策略及审批在编排线程按请求顺序处理；只有获准的读取进入工作线程。每个读取使用独立临时状态及工作区授权快照，不能访问持久 Shell 或其他工具资源。归档、输出预算、读取观察合并、结果投影和进度收尾回到编排线程，按请求顺序完成，不按线程完成顺序归属观察。补丁只接受后续模型请求实际看见的行，不能因批次读取提前获得修改资格。

注册表二次预检结束后、发出执行事件和启动线程前，再由编排层检查取消；取消的待派发批次不计为真实工具动作。路径在准入后变化仍由读取处理器重新校验，返回现有路径拒绝并转回串行授权，不将目标变化变成批次协议异常。所有已经准入但未派发的动作也必须显式关闭其收尾上下文。

取消在批次准入和派发前检查；已经派发的有限本地读取等待收尾并记录结果，再报告中断，不承诺抢占文件系统调用。批次异常须收回全部工作线程、记录其他已完成结果并释放执行锁，后续写入不能越过批次。现有对外工具字段、错误码、执行阶段和授权语义不变。

批次期间如果资源代际因取消清理而推进，读取观察不得重新合并进已清理的共享状态；已完成结果仍保留运行归属并记录。并发批次按整批墙钟时间累计工具耗时，避免对等待同一批次重复计时。

阶段跟踪由可信内置实现声明。Shell 在创建或使用实际执行进程前开启阶段；补丁在写入前开启阶段；测试命令复用 Shell 的阶段。阶段开启后不可通过普通返回结果回退。参数、路径或测试命令发现失败发生在阶段开启前时，可证明动作未启动；第三方工具没有可信跟踪时默认未知。

启动前的路径拒绝可以经过工作区授权后重试；合成授权拒绝保留未启动事实。命令执行后报告路径越界不得重跑。失败已启动的测试仍可能产生部分效果，必须核对，不凭测试工具名称豁免。

## 资源归属与清理

上下文捕获注册表资源代际。创建 Shell、登记状态与重置共用资源锁；重置先推进代际，旧上下文不得补建资源。关闭成为 Shell 实例终态，超时和协议失配的返回路径不会自行重启；下一次合法工具调用可创建新实例。

清理逐项尝试，失败项保留供重试。回调替换或新增资源时，清理不得删除新实例或报告全部成功。已成功清理的持久资源在同一清理重试内不会重复关闭。

## 本地进程停止的证据范围

具备 `/proc` 与不回收等待接口的本机 Linux 使用独立进程组。组长退出检查不提前回收 PID；在升级到 SIGKILL 及验证组内无活动成员之后，才回收组长，避免对可能复用的组号发送信号。检查退出与最终回收共用所有权锁。忽略 SIGTERM 的同组子进程也须停止，超时或归属不可验证时保留清理失败。

主动脱离会话的子进程不在进程组停止证明范围内。其他平台只提供直接子进程关闭能力，不宣称完整子进程树已停止。远端操作也不能通过本地连接关闭证明停止。上述未知结果必须继续保留恢复门禁。

扫描 `/proc` 时，目录已列出但进程随后消失所产生的 FileNotFoundError 或 ProcessLookupError 均按该进程不存在继续检查；权限错误和其他异常仍保留为清理失败，不把无法检查当作已停止。
