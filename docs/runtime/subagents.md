# 子代理与任务委派

状态：当前本地机制与分布式目标边界。子代理属于 Agent Runtime；能力工具只是提交委派操作的入口。

## 独立会话与受限合同

子会话从 inherit、fresh 或 image 启动，拥有独立消息、运行记录、能力与任务状态。继承是创建时快照，不是持续共享；镜像是启动材料，不是正在运行的会话。

委派合同结构化约束允许副作用、资源、证据与能力范围。协调器不能从自然语言任务标题推导写入或 Shell 权限；缺失或无效合同不能回退为全权限。runner 领取成员后签发并校验绑定当前 attempt 的后台执行授权。

当前只读合同拒绝写入，结构化写入也限制资源。Shell、测试、网络或破坏性能力需要额外审批，后台无通道时阻塞。子代理可以提出权限需求，但不能自己批准。readonly 模式仍优先。

## 生命周期与公共状态

当前成员使用 ready、running、blocked、completed、failed、cancelled。完成、等待许可、运行异常和用户取消必须分别记录。

公共状态是有界协作投影，包含来源、成员、attempt、任务、证据和结果摘要，不是原始会话共享。成员领取与提交按条件更新；取消或续跑后，旧 attempt 的迟到结果不能覆盖新状态。完整运行过程留在成员归档。

相同交付物的修复优先续跑原成员，保留已知问题和验证事实。独立探索或隔离需求可以创建新会话，但不以重建成员绕过约束。

## 交付与集成

runner 校验输出、blocker、证据与引用后形成唯一终态，投影到会话、集群和公共状态。引擎异常后的部分成功事实应保留，不能只发布一句错误。

父任务消费经验证的结构化交付，不能因子代理文本声称成功就完成。缺少证据、状态冲突、明确复核要求或重要副作用时进行有界集成验证，避免完整重做已验收工作。

## 并发与远程限制

当前存在本地并发 ready runner、文件锁和原子更新；这些机制不提供远程分布式锁或自动崩溃续跑。子会话默认不获得递归编排能力，防止无监督委派扩大运行规模。

未来远程任务适配需复用任务、授权和证据语义，本地记录不能冒充远端权威状态。长期 worker、资源租约与跨节点故障恢复见[执行目标设计](../design/execution-targets.md)。
