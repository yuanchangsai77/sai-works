# 上下文生命周期

状态：当前机制与目标边界。上下文属于 Agent Runtime 的工作集，Workspace 提供资源事实；模型输入不是权威状态仓库。

## 来源与预算

当前来源包括项目规则、相关工作区摘要、用户显式文件、会话历史、工具结果、已激活 Skill 指令以及检查点投影。ContextPackager 统一排序和限制；工具结果先经过单项输出预算。

必需系统指令与当前请求优先完整容纳，其余运行态和历史分配剩余空间。必需部分本身超限时明确失败，不发送被静默截断的用户请求。先排除调用与返回不配对、最终不会发送的观察，再按总字符预算核算完整候选请求；整体能容纳时不因系统内容等局部固定配额触发压缩。整体超限时，先按必需内容、最新观察和最近完整对话的既有优先级分配空间；未能原样容纳的历史对话和观察合成一份低权威的工作集材料，调用模型做整体语义摘要，再重新核算预算。同一运行会话内，材料未变且摘要仍能装入时复用摘要；历史或观察仅追加时，以先前摘要和新增材料更新摘要。材料缩减、改写或工作区版本变化时重新摘要原始材料。其他可选上下文的相同摘要也在本次运行内复用。摘要不授予已读文件行或完整观察的资格；若最新观察本身也放不下，纳入摘要并允许后续按来源回查。压缩失败不能靠截取摘要冒充成功。摘要请求计入现有模型尝试次数限制，临时传输错误沿用模型重试；连续请求之间检查取消和显式启用的运行时限。确实没有容纳摘要的空间时记录省略。历史选择保持最近连续完整轮次，省略要可观察。

当前运行的观察以独立调用/结果单元参与剩余预算分配，不固定限制在总预算的 10%，也不按 30 条字符串项淘汰。先保证最新观察，再为最近一组完整历史对话保留空间，其余观察与对话使用剩余容量。超限观察保留来源、状态和明确截断标记；不能把多条结果的首尾拼成一个无来源片段。原生工具协议保留完整调用/返回配对，其他协议使用同源的结构化文本投影，运行时恢复提示单独投影。

这里的最新观察包含其后的运行时反馈，预算按整个后缀计算，不能用最后一条短提示代替实际工具结果。较长的普通模型说明不能先占满预算并挤掉最近观察；同一调用中的说明文字可裁剪，调用结构与结果配对仍完整保留。可选恢复摘要只在这些观察与最近完整对话预留之后使用空间，不能挤掉最近的用户约束。重复观察按工具、来源、查询条件和输出共同判定；不同查询的无匹配结果是不同发现，读取范围按实际返回行段区分。

进展判断覆盖整轮成功观察，包括扩展工具的新结果；重复读取公共配置不能掩盖同轮的新增发现。执行时的工作区作为观察来源的一部分单独记录，不借用持久 Shell 的 cwd；相同相对路径和搜索条件在不同工作区中不是同一观察。合成恢复提示不算新增事实，单纯改变执行调用参数但返回同样结果也不算进展。

文件观察以受保护头部给出来源、资源版本、实际返回范围和本次正文是否完整；总行数等领域信息仍保留在工具元数据。工具 schema 的序列化字符占用计入预算预留，字符预算仍不等于模型 tokenizer 的精确 token 预算。请求诊断分别记录系统、运行态和观察的裁剪及省略，不用对话省略数代替全部裁剪事实。

恢复通过既有 run_id 从运行目录读取结构化观察索引，校验会话、授权工作区及归档内容，不解析人类日志来重建事实。未被结构化归档覆盖的单条旧轨迹按低置信度文字摘要兼容，即使同次运行的其他记录已恢复，也将该条整条保留或省略。恢复只投影摘要及完整引用，不直接重注入全部旧输出。摘要明确标为部分证据，完整材料缺失时允许有目的地回查；不要求模型复用不可见的完整结果。普通分析与修改任务都受无新增观察的重复探索检测保护，该机制不授予文件修改权限，也不把分析任务变成写入契约。

工具适配层声明来源语义，核心进展策略不按工具名猜测查询、版本或范围。未知扩展工具保守地由运行预算兜底。操作去重、观察新增与任务完成是三个独立判断；读取缓存须通过资源版本校验，写入和执行仍保留已有副作用去重。

模型请求组装后记录实际可见观察、完整性和可见行段。未使用内置请求组装器的模型客户端，以调用前已提供给客户端的工具结果作为可见范围。补丁需要借助先前读取来定位或处理无旧内容的插入时，已查看状态只接受工具输出预算与本次模型请求中均完整显示的行；同轮刚执行的读取须等到结果进入下一次模型请求后才可作为依据。带旧内容且与当前文件指定位置精确匹配的补丁可直接执行，不要求先前读取；内容或位置不匹配时不能仅凭裁剪、省略或归档中的行来推断修改目标。省略或片段不会成为禁止重读的依据。机制与验收见[观察记录与模型工作集](../design/observation-working-set.md)。

会话保存、提示裁剪与会话压缩是不同操作。模型感知 token 预算、完整语义摘要和统一引用回查仍有差距。

## 当前会话压缩与恢复边界

当前 /compact 由交互壳协调。对有持久化存储的会话，先生成摘要并归档原消息，再以摘要和归档引用替换当前消息；原消息可通过 /history 回查。摘要生成失败时不压缩，持久化失败时恢复原消息和相关会话字段。分块压缩及合并摘要时，要求模型保留用户问题和回答中的精确值、标识符及已完成任务的重要事实；后续重复或无关消息不应使早期事实被误判为未记录。为兼容旧会话，存储层保留既有消息角色；模型请求组装时识别会话压缩摘要，把它投影为可再压缩的低权威历史材料，不作为系统指令，也不挤掉当前请求与必需检查点。压缩请求的输入有界，摘要输出通过模型请求的整体预算再次核算。

压缩保留同一会话身份、工作空间状态、已批准路径及已激活能力，不创建新会话。历史运行记录仍保留，但推进上下文代次，并将历史轨迹边界设置为最近一次运行，避免旧轨迹重新进入新工作集。

最近恢复状态独立于会话消息压缩，保留未完成任务的检查点、blocker 和最近运行恢复信息。历史轨迹仍按上下文代次隔离，不把压缩前的完整材料重新注入模型；继续任务时由运行时核对任务身份、工作区和证据有效性。

后续仍需完善跨进程恢复和任意动作重放；当前字段见[运行状态参考](../reference/runtime-state.md)。

## 软件项目是当前场景适配

ProjectRulesLoader 在项目边界内加载 AGENTS.md，近目录规则优先。WorkspaceSummaryLoader 按请求相关性收集有界摘要；ExplicitContextLoader 展开明确的文件、目录和 glob，限制工作区范围及二进制输入。

ProjectDetector 为摘要和测试工具复用项目事实。当前识别 Python、Node、Rust、Go 标记；仅在有可靠测试线索时提供默认命令。显式测试命令优先；没有可靠候选或存在歧义则返回现有错误，不能猜测执行。

测试环境优先项目虚拟环境，再使用当前解释器；受控 src layout 设置按现有解析器处理。通用 Runtime 不要求每个 Workspace 都具备项目标记或测试命令。

## 信任与恢复

外部内容、工具观察与子代理结果不能因进入上下文就获得策略权威。来源与用途应明确，完整材料留在受控存储，当前有效摘要进入模型工作集。

恢复重新构造上下文，不无限拼接旧运行投影。能力指令由激活集拥有，不创建独立 trigger 注入旁路。
