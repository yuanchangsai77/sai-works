# 上下文生命周期

状态：当前机制与目标边界。上下文属于 Agent Runtime 的工作集，Workspace 提供资源事实；模型输入不是权威状态仓库。

## 来源与预算

当前来源包括项目规则、相关工作区摘要、用户显式文件、会话历史、工具结果、已激活 Skill 指令以及检查点投影。ContextPackager 统一排序和限制；工具结果先经过单项输出预算。

必需系统指令与当前请求优先完整容纳，其余运行态和历史分配剩余空间。必需部分本身超限时明确失败，不发送被静默截断的用户请求。历史选择保持最近连续完整轮次，省略要可观察。

会话保存、提示裁剪与会话压缩是不同操作。模型感知 token 预算、完整语义摘要和统一引用回查仍有差距。

## 当前会话压缩与恢复边界

当前 /compact 由交互壳协调。对有持久化存储的会话，先生成摘要并归档原消息，再以摘要和归档引用替换当前消息；原消息可通过 /history 回查。摘要生成失败时不压缩，持久化失败时恢复原消息和相关会话字段。

压缩保留同一会话身份、工作空间状态、已批准路径及已激活能力，不创建新会话。历史运行记录仍保留，但推进上下文代次，并将历史轨迹边界设置为最近一次运行，避免旧轨迹重新进入新工作集。

同时，最近恢复状态被替换为空状态，其中的检查点、blocker 和最近运行恢复信息不再作为当前恢复入口。历史材料仍在并不等于未完成任务的结构化恢复状态完整保留；压缩后继续任务不能假设仍沿用压缩前的检查点。

目标是将消息摘要与任务恢复状态的生命周期分开，使压缩保留仍有效的任务约束、证据和阻塞，同时保持授权范围不扩大。这项完整恢复语义尚不能作为当前压缩行为的保证。当前字段见[运行状态参考](../reference/runtime-state.md)。

## 软件项目是当前场景适配

ProjectRulesLoader 在项目边界内加载 AGENTS.md，近目录规则优先。WorkspaceSummaryLoader 按请求相关性收集有界摘要；ExplicitContextLoader 展开明确的文件、目录和 glob，限制工作区范围及二进制输入。

ProjectDetector 为摘要和测试工具复用项目事实。当前识别 Python、Node、Rust、Go 标记；仅在有可靠测试线索时提供默认命令。显式测试命令优先；没有可靠候选或存在歧义则返回现有错误，不能猜测执行。

测试环境优先项目虚拟环境，再使用当前解释器；受控 src layout 设置按现有解析器处理。通用 Runtime 不要求每个 Workspace 都具备项目标记或测试命令。

## 信任与恢复

外部内容、工具观察与子代理结果不能因进入上下文就获得策略权威。来源与用途应明确，完整材料留在受控存储，当前有效摘要进入模型工作集。

恢复重新构造上下文，不无限拼接旧运行投影。能力指令由激活集拥有，不创建独立 trigger 注入旁路。
