# 会话工作区状态

持久化 session 拥有初始根、活动根与批准路径。任务 checkpoint 只保存进度；任务结束和恢复不应撤销会话授权。

交互聊天和单次执行必须统一消费 terminal summary 中的 workspace state。恢复入口同时传入保存的状态；中断也必须保存已发生的授权。

普通外部访问只增加批准路径。workspace_open 明确改变相对路径的基准并刷新项目上下文。切换时清空当前工具去重缓存，防止复用其他项目的同名文件结果，或跳过再次打开目录的动作。

子代理能力请求属于无资源副作用的控制操作，即使合同只覆盖部分文件也可提交。父代理升级 effects 时保留已有 required_evidence，能力范围和交付要求独立管理。

验证覆盖连续聊天、恢复入口、工作区往返切换、受限资源下能力请求和合同升级后的交付要求。

持久 Shell 在活动根变化后重新创建，以便默认命令跟随新项目。普通 Shell 内部 cd 仍按既有生命周期保留。

安全模式和路径授权见[执行安全](execution-safety.md)；工具字段见[工具契约](../reference/tool-contract.md)。
