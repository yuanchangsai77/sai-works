# 经验与长期认知的探索边界

状态：未实现的专项方向，不是新增核心域或近期交付承诺。

## 经验与偏好：保留治理语义

经验是可复用且有适用条件的知识，偏好是人的选择，Policy 是执行权限。三者不互相替代。模型切换不能改变记录身份或使旧许可重新有效。

经验从候选进入可用状态前，需要来源、适用环境和验证证据；重复出现只触发候选，不证明正确。冲突、过期与环境不匹配要可见。检索先做主体、范围、版本和权限硬过滤，再做相关性排序。

显式长期偏好、推断候选和当前任务临时选择分开管理。敏感、付费、数据出域和现实副作用的长期选择不能仅凭行为推断升级。具体当前请求优先于普通默认偏好，Policy 独立裁决。

向量索引是可重建投影，不拥有第二套授权与删除语义。撤销记录后不得通过摘要、索引或缓存继续泄露。经验晋升为 Skill 是独立发布流程，需要维护者、输入输出、风险声明、测试和版本治理，不能自动变成可执行资产。

这些机制尚未完整实现；只有真实复用需求出现后再选择存储、检索与确认策略。

## 非 Coding 场景：保留验证用途

研究、数据分析、运维和设备操作用于检验 Workspace、Capability、Policy、Execution Target 与 Evidence 的通用性。摄像头、投喂、空调、新闻等具体业务不进入内核枚举。

选择一个真实闭环，验证命令接收与现实效果、访问与执行权限、故障恢复和数据范围；避免先建设业务功能目录。

## 连续认知：保留研究假设

持续输入、有限工作集、原始证据回查和受约束分支值得研究。神经状态、KV、latent memory 与内部模型调度属于 Model Core 研究边界，不由 SaiWorks 接口强制规定。

精选研究笔记见[连续认知研究摘要](../archive/research/continuous-cognition.md)。它保留假设、责任边界和验证问题，删除固定网络结构、未验证效果宣称及重复比喻。
