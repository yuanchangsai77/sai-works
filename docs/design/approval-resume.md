# 审批等待与续跑设计

状态：审批等待、续跑及批准范围等协商项已于 2026-10-15 确认；本文保留尚未闭合的挂起、批准消费、调度和预算设计，不维护进度表。当前工作只见[路线图](../roadmap.md)，已实施的审批和取消事实只见[运行控制参考](../reference/runtime-control.md)。

## 当前边界与兼容责任

任务观察已有同进程快照、修订游标与观察资格；审批存储已有独立控制资格、记录有效期、决定冲突和取消接受点，随后已有活动 Run 取消桥接与动作启动排序。上述实现不等于执行循环已支持挂起/续跑，也不表示批准已被实际动作消费。当前快照和数据版本分别以[任务观察](../reference/runtime-observation.md)和[运行控制](../reference/runtime-control.md)为唯一现行定义，不在本页复制字段、状态枚举或数据库版本。

设计不发布 HTTP/WebSocket API，不改变旧 Session JSON、TaskCheckpoint 阶段和 ExecutionSummary 终态。具体新增请求响应、字段语义、审批快照扩展或持久化升级必须在实施前说明兼容影响并确认；已确认的行为方向不替代新增契约协商。旧同步入口在迁移期保持可用。

## 批准范围与资格

人为批准只覆盖一个确定动作，绑定任务、提交、规范化动作参数、执行工作区及政策要求的范围；任一变化重新核验，不复用同名工具的其他参数。Policy 直接允许的动作不弹窗。由更宽复用收敛为单动作批准可能增加审批次数，这一行为影响已有确认，不能又扩大为风险组授权。

观察资格不能控制任务，控制资格须分别核验取消与批准权限。不能凭 task_id、调用者角色字符串或公共摘要中的“已批准”获得资格；跨进程资格传递与 Gateway 身份属于独立设计。

## 挂起与原子接受等待

在需要人的决定且动作尚未执行时，执行循环交回内部挂起事实，而不是伪造最终 ExecutionSummary。Runtime 事务保存审批、续跑材料、等待状态和 revision，提交成功后才通知观察者、调用兼容适配并释放执行槽；存储失败不得执行待批动作或先声称已经挂起。

续跑材料保存原 Task/submission/Run 及工作区绑定、待决定动作和剩余动作、已完成动作与证据、必要观察、当前轮次、去重与进度状态，以及已消耗执行时间、模型尝试和连续超时。只持久化有版本的结构化数据，不序列化线程、窗口、连接、工具进程或可执行对象。工具状态不能安全恢复、来源失效或外部效果未知时保留核对要求。

默认关闭模型连接和普通工具进程，外部长进程另行管理。不得为了恢复隐式重建可能有副作用的工具状态，也不能用新接受记录重置预算。

## 调度、预算与消费

等待不消耗执行或模型预算，TTL 独立计量。任务等待时其他 Session 可使用执行槽，同 Session 后续提交不得越过前序等待任务；同一任务不能产生两个活跃续跑者。

批准后重新排队，取得槽后复核实时政策、工作区、动作指纹、观察版本、有效期及剩余预算。不能重新请求模型生成已确定的待批动作，不能重放已完成动作。批准消费、取消接受和动作启动资格必须由同一权威事务排序；内存 Event 不能代替这一裁决。

已接受取消后的迟到批准不得启动新动作；已经启动的动作沿现行中断和未知结果核对路径处理。过期不执行且保留可恢复任务，重新申请形成新审批身份，旧身份不得重新激活。拒绝沿用执行政策，不由 UI 自行决定任务终态。

## 同步入口与界面接入

旧同步调用可等待最终结果，但等待不能占用执行槽或将界面内回调对象作为审批唯一记录。挂起和预算续接闭合后，CLI/TUI/桌面应用再迁移到共同观察与控制；全部迁移且兼容验收通过前，不删除旧入口。关闭窗口后续跑依赖独立服务生命周期，不由同进程审批功能承诺。

## 验收约束

- 保存失败不执行；等待释放槽，其他 Session 可运行，同 Session 不越序。
- 相同或冲突决定结果一致，不重复消费批准或执行动作；过期、取消竞争和迟到回复有明确裁决。
- 续跑保留预算、原任务身份、已完成动作及有效观察；未知外部结果不自动重试。
- 观察断开不改写终态；无控制资格不能决定；旧同步入口和持久化升级失败保持既有保障。
- 新字段及升级兼容性以实施时获确认的现行参考为准，不能把本设计作为已交付接口。
