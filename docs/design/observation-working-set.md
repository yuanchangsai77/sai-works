# 观察记录与模型工作集

状态：内部重构设计与验收基线。复用运行目录归档，不增加数据库，不改变 ToolAction、ToolResult、Session JSON 或跨端请求/响应 schema。

## 所有权与数据流

工具适配层说明目标、查询条件、资源版本与返回范围；注册器补上可信执行工作区和身份，形成运行时观察记录。未知工具保留完整规范化参数，语义置信度为未知，不根据权限风险推断是否推进任务。

观察记录包含操作身份、证据身份、成功状态、完整性、摘要与完整材料引用。完整材料在模型预算裁剪前经脱敏归档，归档失败不产生虚假引用。小型进程内记录保留身份和有界正文，归档按内容身份去重。观察索引位于已有 run 目录，恢复通过既有 run_id 查找，校验会话和已授权资源范围；历史记录不自动获得当前修改或完成证据资格。

模型上下文、恢复输入和人类可读日志是观察记录的独立投影。恢复不解析日志摘要来重建事实，不把引用拼进可随意裁剪的正文。缺少结构化归档的单条旧轨迹仍作为完整保留或整体省略的低置信度历史摘要兼容；同一次运行中其他记录已恢复时也保留这些缺失项，不推断其内容完整或仍有效。

## 三种不同判断

操作复用要求同一规范化请求和仍有效的资源状态；未知状态不安全复用读取结果。失败与权限拒绝继续沿用现有非重试门禁。修改和执行的现实效果不因观察相同而被重复执行。成功读取的缓存复用不受副作用操作的重复次数门禁限制，是否停滞由整轮观察与实际可见性判断。文本动作协议投影仅发送角色和正文，不保留原生工具调用字段；内部可见性信息保留到组装阶段。

观察新增按目标、版本、覆盖范围及结果共同识别。不同 Git 版本、不同查询、不同工作区即使正文相同，也可能是不同覆盖事实。搜索达到结果上限或命令输出先被截断时，不能宣称观察完整。分页上限等展示参数只有工具适配层能在实际返回范围支持时规范化。

任务推进仍以既有检查点、交付和证据门禁为准。新增输出不是交付完成证明；未知工具不会因新时间戳自动获得完成证据。合成运行时控制提示不制造新事实。

## 可见性与裁剪

上下文选择完成后记录每条观察实际发送的正文范围、是否完整及引用是否可见。完整归档存在不等于完整正文已送达模型。未知、已省略或只送达片段的结果，不能成为“模型已知、禁止重读”的依据；允许重新提供或有目的地回查。

引用、来源和调用/返回配对是原子结构，正文才可裁剪；调用旁的普通模型说明也可缩短，以保住最近观察。投影在预算分配后输出最终 API 消息，内部记录与可见性标记不得发送给模型端点。补丁依赖已查看行时，须经过单项工具输出与本次模型请求两层可见性确认，授权绑定到具体读取记录；同轮新读取即使与旧读取拥有相同观察身份，也不能提前获得授权。补丁若自带旧内容且与当前文件指定位置精确匹配，可直接执行，不以先前读取为门槛。完整候选请求能装入总预算时不压缩，也不为系统内容预设固定份额；整体超限后才按优先级压缩可压缩的本轮上下文，返回正文必须再次通过长度校验，失败时不得静默截取。可选恢复信息及其包装开销不能导致必需内容超限。不能再对整个恢复字符串做破坏性二次裁剪；无空间时整体省略并记录诊断。

重复探索检测只对语义明确、结果完整且对模型可见的重复观察给出确定判断。首先反馈已有证据，持续重复才收尾；存在未知语义时保守使用请求/轮数/时间预算兜底，不增加每轮模型判断调用。

## 验收约束

- 不同版本、查询、资源、工作区的观察不能误合并；资源变化后不能复用过期结果。
- 扩展工具的新事实不能被同轮重复配置读取掩盖；未知语义不能导致硬性停滞判断。
- 未发送的正文和片段不能算模型已知；重复读取已省略材料可以继续。
- 任意预算、长路径和并行调用下，引用完整、调用配对；预算不足时整体省略。
- 恢复直接读取授权范围内的结构化归档，拒绝跨会话、越界路径、损坏索引和无效引用；旧格式保持可读。
- 模型正文裁剪不会修改原记录；归档经过脱敏且不扩大资源访问权限。
