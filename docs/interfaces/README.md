# 交互界面

交互界面收集意图、呈现状态和转交人的决定；Runtime 拥有任务、运行、授权、证据和恢复。

| 文档 | 范围 |
| --- | --- |
| [交互界面与运行时边界](runtime-boundary.md) | 共用交互职责、当前耦合与待明确协议 |
| [命令行界面](cli.md) | 当前输入、命令和运行协调，及需要提取的内核职责 |
| [终端交互界面](tui.md) | 当前展示投影、增量、输入、审批和终端验收边界 |
| [桌面应用](desktop.md) | 桌面参考应用同进程应用控制层与未实现边界 |

桌面参考应用已有同进程控制层和 Tk 参考窗口；真实图形使用和生产分发仍未验收，也没有跨进程服务。IDE、API、Future UI 仍是未来交互界面。共享运行语义先于传输选型，同进程可直接调用，跨进程加适配层。
