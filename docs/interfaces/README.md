# Interface：交互壳

交互壳收集意图、呈现状态和转交人的决定；Runtime 拥有任务、运行、授权、证据和恢复。

| 文档 | 范围 |
| --- | --- |
| [壳与内核边界](runtime-boundary.md) | 共用交互职责、当前耦合与待明确协议 |
| [CLI](cli.md) | 当前输入、命令和运行协调，及需要提取的内核职责 |
| [TUI](tui.md) | 当前展示投影、增量、输入、审批和终端验收边界 |

Desktop、IDE、API、Future UI 是未来壳，不表示已有接口服务。共享运行语义先于传输选型，同进程可直接调用，跨进程加适配层。
