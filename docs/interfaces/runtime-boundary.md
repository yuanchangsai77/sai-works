# 壳与内核边界

状态：当前边界梳理与待实现设计，2026-09-30。本文不是已发布接口契约，不新增请求字段、错误码、方法签名或 transport。

## 当前事实

应用装配返回 CLI 对象。CLI 与 TUI 复用执行引擎，TUI 通过展示层适配。运行进度已有独立抽象；审批通过展示层确认回调连接。会话选择、恢复协调、持久化入口及部分后台执行逻辑仍在 CLI 中。

因此已有共用机制，但没有完整的、可独立供 Desktop/IDE/API 使用的 Runtime 门面。已有 ContextLoader、ToolProvider、ResourceProvider 属于接入扩展点，不是这里讨论的交互控制边界。

## 交互职责地图

以下六类用于核对职责，不要求恰好六个接口或服务。

| 交互职责 | Runtime 应负责 | 壳应负责 |
| --- | --- | --- |
| 任务与运行 | 接收任务、预算、状态、取消与干预语义 | 收集意图、发送操作、呈现状态 |
| 会话与恢复 | 会话关联、持久化与恢复检查 | 会话列表与选择交互 |
| 事件与观察 | 发布可关联的进度、结果和状态事实 | 订阅、展示、管理显示生命周期 |
| 授权交互 | 产生请求、校验决定、保持范围与有效性 | 展示具体动作并转交人的决定 |
| 工作空间与能力 | 管理资源范围、能力目录和激活状态 | 查询、选择和解释当前环境 |
| 执行记录与证据 | 保存与查询结果、来源、检查点及访问约束 | 展示和帮助检查 |

## 待设计事项

先明确运行身份与生命周期、状态查询与事件关联、审批等待与取消、重新连接后的观察、并发运行限制、记录保留与访问约束，再选择传输形式。现有同步调用和回调不能未经评估直接视为远程协议。

同进程 CLI/TUI 可以直接调用；跨进程壳通过适配层使用相同语义。网络层不能另建任务状态、权限逻辑或恢复旁路。

任何涉及 App、Cloud、Agent 的字段、错误码或语义变更，先形成兼容性说明并确认。本轮只梳理边界，既有契约保持不变。
